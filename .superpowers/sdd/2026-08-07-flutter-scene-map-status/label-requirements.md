# ラベル機能 要件（ユーザー確認済み・2026-08-07）

これは brainstorming の入力。設計はこの後に提示して承認を得る。

## 対象

Flutter Scene 版 `packages/eqmonitor_map` のみ。現行 MapLibre 版には入れない
（移行期の二重実装を避ける）。

## 1. 強震モニタ観測点ラベル

- 既定表示は **観測点名のみ**。
- **引数で震度値も表示可能にする**（呼び出し側が選択する。renderer が勝手に決めない）。
  → label spec に「何を出すか」を持たせる API 設計が必要。

## 2. 地域ごとの震度アイコンのラベル

- **地域名をアイコンの横に表示**する。
- 配置は **9方向の候補**から、衝突しない方向を選ぶ。
- **どの方向も衝突する場合は地域名を出さない**（無理に重ねない）。
  → 震度アイコン自体は常に表示され、消えるのは地域名ラベルのみ。

注: 9方向 = MapLibre の `text-variable-anchor` と同じ候補集合
（center / left / right / top / bottom / top-left / top-right / bottom-left / bottom-right）。
設計正本は right/left/up/down の4候補を想定していたため、**設計正本の更新が必要**。

## 3. 密度制御（観測点は全国 約1000地点）

**ズーム + 震度しきい値 + 衝突判定の組み合わせ**を採用する。3つの併用であり、
どれか単独ではない。設計時に決めるべき点:

- どのズームからラベルを出し始めるか
- 震度しきい値をいくつにするか、しきい値は固定かユーザー設定か
- 衝突時の優先順位（震度が高い地点を優先するのが自然か）
- しきい値未満の地点はマーカーだけ残すのか、マーカーごと消すのか

## 設計正本への影響

`docs/superpowers/specs/2026-08-02-eqmonitor-map-renderer-design.md` は
「ラベルの地理anchorはPMTiles生成時に専用Pointレイヤーへ1点だけ格納する」
「表示位置候補はrendererが実測文字サイズとDPRからscreen上に生成する」と定めている。

観測点ラベルと地域震度ラベルは **PMTiles 由来の静的ラベルではなく動的データ由来**の
ラベルであるため、設計正本のラベル節が想定する経路と異なる。動的 source から
label anchor を供給する経路を設計に追加する必要がある。
