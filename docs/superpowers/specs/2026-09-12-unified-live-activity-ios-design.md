# 統合 Live Activity の新デザイン仕様

2026-09-12のユーザー指示に基づき、旧形式・旧デザインを全面置換する。
対象は Lock Screen、Dynamic Island の Expanded / Compact / Minimal、ローカルデバッグ画面。
新しい wire 契約は backend schemaVersion 2 のみ。互換機能・移行機能は作らない。

## 情報の構成

カードは「情報種別と更新時刻 → 地域の主要指標 → 震源要約 → 受信ソース要約」の順。
主要指標を大きくし、地名・予想/最大/推計の区別を同じ視線の範囲に置く。
受信した `primary` を表示する。時刻経過やフロント独自の重要度で切り替えない。

| primary | 種別見出し | 主指標 | 補助情報 |
| --- | --- | --- | --- |
| shake_detection | 揺れを検知 / 揺れの検知終了 | 地域のピークレベルと地域名 | 全体の最大レベル、検知時刻 |
| eew | 緊急地震速報・警報 / 予報 | 地域の予想震度＋到達予想 | 全国の予想最大震度、震源、M、深さ、報数 |
| earthquake | 地震情報 / 推計震度分布図 | 地域の震度、なければ全国の最大震度 | 震源、Magnitude、深さ、発生時刻、受信情報種別 |

受信地域をGPSの現在地だと推測しない。名称は location の値を使う。
EEW予想震度は提供された全階級を対象にする。0〜3を表示閾値で隠さない。
地域値がなければ全国値を「最大 / MAX」と明示する。地域値と同じ無印バッジを使わない。
揺れレベルは「微弱・弱い・揺れ・強い・非常に強い」の語で示し、震度数値へ変換しない。

## 視覚言語

- 大きな種別アイコン、左揃えの見出し、余白のある2列の主指標を使う。
- 背景は light: `#F7F8FA` / dark: `#11161D`、主文字は `#17212B` / `#F5F7FA`。補助文字も十分なコントラストを確保する。
- 警報の赤、予報/揺れ検知の琥珀、地震情報の青を種別アイコンと短いラベルに使用する。面全体を警告色で塗らない。
- 震度そのものはアプリの震度階級色を使う。色だけで判断させず「地域の予想震度」「最大震度」のラベルを併記する。
- 文字はシステムフォント、数値はシステムの rounded / monospacedDigit。旧ストライプ背景・旧EEWレイアウトを流用しない。
- 間隔は4/8/12/16、カード内余白は16を初期値とする。文字を含む領域の高さは内容に追従させる。
- SwiftUI の色/間隔/文字役割は `UnifiedLiveActivityStyle` にまとめ、Viewごとに値を複製しない。

## 表示形態

- **Lock Screen**: 左に地域名と主要指標、右に到達予想または種別に適した補助情報。下に震源要約と、実際に存在するソースだけの短いラベルを置く。
- **Expanded**: leadingに種別、trailingに報数/更新時刻、bottomに主指標と震源要約。狭い場合は補助文字を減らし、指標・意味・地域を残す。
- **Compact**: leadingに `予` / `震` / `揺` を含む指標、trailingにEEW到達予想または短い状態名。全国値なら `MAX` を優先する。
- **Minimal**: 同じく意味を伴う指標を1組表示する。全国値を地域値と区別できないサイズまで縮めず、省スペース用の専用配置を作る。
- 画面のソースラベルは履歴や進捗バーに見せない。未受信の段階を表示しない。揺れ終了は「揺れ検知 終了・最大…」、最終EEWは「EEW 最終第…報」。
- 到達予想は `Text(timerInterval:countsDown:)` を使用。到達後は00:00で止まり、主表示やActivityの終了を引き起こさない。

## 欠損・取消・複合状態

- 地域欠損は「地域情報なし」。全体の値もなければ「震度情報なし」。0や安全を示す色へ置換しない。
- 到達予想欠損は「到達予想なし」。地域PLUMは「PLUM法による検知」。到達日時を補わない。
- 取消は該当ソースのカードを中立色と取消文言へ変更し、古い値を有効な予想/観測として出さない。他ソースの有効情報は保つ。
- ended の揺れピークを維持する。既に終了した揺れを「現在も揺れている」と読めるアニメーションで表現しない。
- 地震情報の Magnitude は M数値 / M不明 / M8以上の巨大地震 / 項目なしを区別する。
- IXAC41単独は推計として扱い、観測値だと断定しない。情報種別配列を単一種別へ潰さない。
- 長い地名・見出しは複数行を許可する。縮小より補助情報の省略を優先し、主指標を切り取らない。
- VoiceOverは「地域名、予想/最大/推計、指標、到達予想、状態」の順。色・点滅・位置だけに意味を持たせない。

## デバッグ体験と検証

統合 Activity の一覧、シナリオ選択、Start / Update / End、JSON編集を一つの画面にまとめる。
旧種別の選択はなくす。primaryや各ブロックの有無はシナリオの内容として編集する。
mockは [デザインプレビュー](../plans/unified-live-activity-preview.html)。静的なサンプルで、ネイティブ表示を保証するものではない。
SwiftUI Preview / 実機で Light / Dark、全primary、欠損、取消、Magnitude各形態、最大文字サイズ、Compact/Minimalを確認する。
具体的な実装・削除ファイルとテストは [実装計画](../plans/2026-09-12-unified-live-activity-ios.md)に従う。
