# 地震履歴詳細 周辺の地震活動 設計

- 作成日: 2026-07-31
- ステータス: 設計承認済み

## 目的

規模の大きな通常地震について、基準地震の前後に近隣で発生した地震の件数、時間推移、空間分布、個別情報を地震履歴詳細画面から追跡できるようにする。

「前震」「余震」は事後にも一意に断定できないため、本機能では自動分類しない。基準地震より前・後に発生した「周辺の地震活動」として、検索条件と取得できた事実を客観的に表示する。

## データ範囲

初期版は既存の地震履歴 API が返す有感地震・発表対象の地震のみを使用する。無感地震や微小地震を含む観測地震の全件を表すものではないため、専用画面に次の趣旨を明記する。

> この表示は EQMonitor が取得した地震情報を集計したもので、観測されたすべての地震を網羅するものではありません。

気象庁の一元化震源カタログなど、微小地震を含む別データソースの取り込みは初期版の対象外とする。取得と可視化の責務を分離し、将来データソースを置き換えられる構成にする。

## 入口の表示条件

地震履歴詳細画面に「周辺の地震活動」概要カードを表示する。次の条件をすべて満たす地震だけを対象とする。

- `EarthquakeType.normal`
- `originTime` が取得できる
- 震源座標が取得できる
- `M6.0 以上` または `最大震度 5弱以上`

マグニチュードと最大震度の一方が不明でも、もう一方が閾値を満たせば対象とする。強弱が不明な `震度5` と `震度6` は既存モデルの意味どおり「5弱以上」「6弱以上」として閾値を満たす。両方が不明、または両方とも閾値未満の場合は対象外とする。

基準地震の深さが不明でも利用できる。その場合は深さ条件を適用せず、探索範囲設定にも深さ項目を表示しない。

## 概要カード

概要カードの初期検索条件は次のとおりとする。

- 期間: 基準地震の発生 1 日前から 7 日後まで
- 水平範囲: 震源から半径 25 km
- 深さ範囲: 基準震源の深さから ±20 km
- 地震種別: `EarthquakeType.normal`
- 基準地震自身: 集計から除外

基準地震の発生から 7 日を経過していない場合、実効終了時刻は現在時刻とする。

カードには次を表示する。

- 基準地震より前 1 日間の件数
- 基準地震の発生後から 7 日後までの件数
- 期間内の最大震度
- 期間内の最大マグニチュード
- 期間内で最後に発生した地震の発生時刻

該当地震がない場合もカードを省略せず、前後それぞれを `0件` と表示する。最大震度、最大マグニチュード、最終発生時刻は該当なしとして表示する。

カードをタップすると、基準地震の `eventId` を渡して「周辺の地震活動」専用画面へ遷移する。

## 専用画面

専用画面は上から次の順に構成する。

1. 基準地震の概要と現在の抽出条件
2. コンパクトな震央分布地図
3. 最大震度別・時間帯別の積み上げ棒グラフ
4. 条件に該当する地震一覧
5. データ範囲に関する注記

### 基準地震と抽出条件

基準地震の発生時刻、震源地、マグニチュード、最大震度を表示する。現在選択中の前後期間、半径、深さ幅、集計間隔も確認できるようにする。

### 震央分布地図

- 基準地震を専用マーカーで強調する。
- 周辺地震を最大震度に対応する色の円で表示する。
- 現在の検索半径を円で表示する。
- 周辺地震のマーカーを選択すると、発生時刻、震源地、マグニチュード、最大震度を表示する。
- 選択した周辺地震から既存の地震履歴詳細画面へ遷移できる。
- 棒グラフで時間帯を選択している間は、その時間帯の周辺地震だけを表示する。

### 時間別発生回数グラフ

横軸を `originTime`、縦軸を発生回数とする積み上げ棒グラフを表示する。基準地震の発生時刻を縦の境界線で示す。

各地震を次の区分へ分類する。

- 震度 0
- 震度 1
- 震度 2
- 震度 3
- 震度 4
- 震度 5（強弱不明）
- 震度 5弱
- 震度 5強
- 震度 6（強弱不明）
- 震度 6弱
- 震度 6強
- 震度 7
- 震度情報なし

既存モデルの強弱不明値を弱・強へ推測変換しない。最大震度が取得できない地震も除外せず、「震度情報なし」として灰色で表示する。全区分の合計は、同じ条件の地震一覧件数と一致させる。

棒をタップすると時間帯を選択状態にし、地図と一覧を該当地震だけに絞り込む。同じ棒の再タップまたは「選択解除」で全件表示へ戻す。

表示期間に応じた初期集計間隔は次のとおりとする。

- 24 時間以内: 1 時間
- 24 時間超から 8 日以内: 6 時間
- 8 日超から 30 日以内: 1 日
- 30 日超: 1 週間

利用者は設定シートから `1時間 / 6時間 / 1日 / 1週間` のいずれかへ変更できる。

### 地震一覧

取得した周辺地震を `originTime` の新しい順で表示する。同一時刻の場合だけ、表示順を安定させる第 2 ソートキーとして `eventId` を使用する。既存の `EarthquakeHistoryListTile` を再利用し、タップすると該当地震の詳細画面へ遷移する。

グラフで時間帯を選択している間は、一覧も同じ時間帯へ絞り込む。

## 検索条件の変更

### 期間

初期期間は発生 1 日前から 7 日後までとし、次の操作を提供する。

- 「前日を表示」: 開始時刻を 1 日前へ延長する
- 「翌日を表示」: 終了時刻を 1 日後へ延長する
- 「初期範囲に戻す」: 発生 1 日前から 7 日後へ戻す

前側は最大 30 日前まで、後側は最大 365 日後までとする。後側の実効上限は `基準地震の発生 365 日後` と `現在時刻` の早い方とし、未来の期間は取得・表示しない。各ボタンは上限へ達した時点で無効化する。

### 空間範囲と集計間隔

設定シートで次を独立して選択できる。

- 半径: `25 / 50 / 100 / 200 km`
- 深さ幅: `±20 / ±50 / ±100 / ±200 km`
- 集計間隔: `1時間 / 6時間 / 1日 / 1週間`

深さ下限は 0 km、上限は既存 API 契約の 2000 km に丸める。基準地震の深さが不明な場合は、深さ幅を表示・適用しない。

## データ取得方式

初期版では専用バックエンド API を追加せず、既存の地震履歴 API を使用する。

1. 指定半径を包含する緯度・経度の外接矩形を算出する。
2. API へ日付範囲、外接矩形、深さ範囲、`EarthquakeType.normal` を指定する。
3. API のカーソル制約に合わせ、内部的に `eventId` カーソルで全ページを取得する。
4. 全件取得後、同一 `eventId` の重複を除去する。
5. `originTime` が不明な地震を除外する。
6. `originTime` で秒単位の期間判定を行う。開始時刻を含み、実効終了時刻も含む。
7. 大圏距離を計算し、指定半径を超える地震を除外する。
8. 深さ条件と基準イベント除外を適用する。
9. `originTime` で並べ替えて集計する。

基準深さが既知の場合、深さ不明の周辺地震は深さ範囲を検証できないため対象外とする。基準深さが不明の場合は深さ条件自体を適用せず、周辺地震の深さが不明でも他の条件を満たせば対象に含める。

API の日付単位検索と矩形検索は候補の絞り込みにだけ使う。利用者へ示す期間と半径は、アプリ内の `originTime` と大圏距離による最終判定で保証する。

`eventId` はイベント識別、重複排除、API の内部カーソル、同一発生時刻の安定ソートにだけ使用する。期間判定、時間集計、前後判定、最終発生時刻、通常の表示順には使用しない。

## アーキテクチャ

本機能は既存の地震履歴 API と詳細画面から利用するため、`app/lib/feature/earthquake_history/` 内に配置する。既存の `seismicity` 画面へ直接依存させず、必要に応じて地図・チャートの描画パターンや汎用化できる部品だけを共有する。

### モデル

`EarthquakeActivityQuery` は次を保持する不変モデルとする。

- 基準イベント ID
- 基準地震の `originTime`
- 基準震源の座標
- 基準震源の深さ。深さ不明時は `null`
- 前側日数と後側日数
- 半径
- 深さ幅。基準深さ不明時は `null`

一覧項目は既存の `EarthquakePartial` を再利用する。集計結果には、完全な対象一覧、概要、時間別震度区分を保持する専用の不変モデルを用意する。

### Repository

`EarthquakeActivityRepository` は既存の `EarthquakeHistoryRepository` に依存し、検索候補の全ページ取得を担当する。ページ取得途中の結果を利用者向け状態として公開しない。

将来専用 API や別カタログへ移行する場合は、この Repository の内部または注入するデータソースを交換し、フィルタ・集計・UI を維持できる境界にする。

### ロジック

次のロジックを Widget から分離し、それぞれ独立してテスト可能にする。

- `EarthquakeActivityBoundsCalculator`: 半径から API 検索用の外接矩形を算出
- `EarthquakeActivityFilter`: `originTime`、種別、深さ、大圏距離、基準イベント除外を判定
- `EarthquakeActivityBinner`: `originTime` を基準に最大震度別の時間ビンを生成
- `EarthquakeActivitySummaryBuilder`: 前後件数、最大震度、最大 M、最終発生時刻を算出

命令的な処理を Widget の private method に置かない。各ロジックは専用クラスとして分離し、必要な依存を Riverpod で注入する。

### Provider と UI

`earthquakeActivityProvider(query)` が取得と最終フィルタ済みの完全な結果を公開する。概要、時間ビン、地図表示、一覧表示は同じ結果から派生させ、画面内で重複した API 取得を行わない。

`EarthquakeActivityPage` は `eventId` を受け取り、既存の `earthquakeHistoryDetailsProvider` から基準地震を取得する。新しい go_router の型安全な Route を追加する。

UI の操作状態である期間、半径、深さ幅、集計間隔、選択中の時間ビンは hooks で管理する。検索・距離計算・集計は Provider と専用ロジックに委譲する。

## リアルタイム更新

アプリが受信した地震の追加・更新・削除が、表示中の検索条件または現在の結果へ影響する場合に `earthquakeActivityProvider(query)` を無効化する。

リアルタイム通知だけでは範囲内か判定できない場合は、表示中の活動画面に限って再取得する。過去の画面を常時ポーリングしない。利用者が専用画面で手動更新する操作も提供する。

再取得中は直前の完全な結果を維持する。再取得に失敗しても既存結果を消去しない。

## 読み込み・エラー・キャッシュ

### 概要カード

- 読み込み中: カード内にスケルトンまたは小さな進捗表示
- 取得成功・0件: 有効な結果として `0件` を表示
- 取得失敗: 短い説明と再試行ボタンを表示
- 例外文字列やレスポンス本文は利用者へ直接表示しない

概要カードの失敗で地震履歴詳細画面全体をエラーにしない。

### 専用画面

複数ページ取得中は「周辺の地震を取得中（取得済み N 件）」のように進捗を表示する。ただし取得途中の値を確定件数、グラフ、地図として表示しない。全ページの取得と検証が成功してから、完全な結果として置き換える。

同じ検索条件に対する直前の完全な結果または既存 HTTP キャッシュがある場合は、再取得中もその結果を表示し、更新中であることと取得日時を示す。再取得に失敗した場合は古い完全な結果を維持し、更新できなかったことを表示する。

キャッシュがなく取得にも失敗した場合だけ、地図・グラフ・一覧の代わりにエラー状態と再試行操作を表示する。条件変更時に以前の条件の結果を新条件の結果として表示しない。不要になった検索条件の取得結果は破棄し、現在の条件へ混入させない。

固定値、推測値、ランダム生成データへフォールバックしない。

## アクセシビリティと表示品質

- Light / Dark モードの両方で最大震度色と選択状態を判別できるようにする。
- 色だけに依存せず、凡例ラベル、ツールチップ、セマンティクスで震度区分を伝える。
- 地図マーカーとグラフの各時間帯に読み上げ用ラベルを付与する。
- 拡大文字で説明、凡例、一覧が overflow しないよう、テキストを含む領域へ固定高さを指定しない。
- 一覧は遅延構築する。
- 読み込み・空・エラー・更新失敗を区別して表示する。

## テスト方針

### 単体テスト

- 半径 `25 / 50 / 100 / 200 km` を包含する外接矩形
- 高緯度、日付境界、深さ 0 km 付近の境界値
- 大圏距離の内側、境界上、外側
- `originTime` による前後期間の秒単位判定
- 基準地震、通常地震以外、発生時刻不明の除外
- 同一 `eventId` の重複除去
- 同一発生時刻での安定ソート
- `1時間 / 6時間 / 1日 / 1週間` のビニング
- 震度 0、強弱不明値、通常の最大震度別区分、「震度情報なし」の合計が対象一覧件数と一致すること
- 最大震度、最大 M、最終発生時刻、前後件数
- ページング完了前に不完全な結果を公開しないこと

### Widget テスト

- 対象条件を満たす場合だけ概要カードを表示
- loading、error、empty、data、古い完全な結果の各状態
- 前日、翌日、初期範囲ボタンと期間上限
- 半径、深さ幅、集計間隔の変更
- 棒グラフ選択による地図と一覧の絞り込み
- 地図マーカーと一覧から地震詳細へ遷移
- 拡大文字、Dark モード、セマンティクスラベル

### 連携テスト

- 複数ページの fixture を使った API 検索条件から最終集計までのデータフロー
- API の日付・矩形候補に含まれるが、秒単位期間または半径外となる地震の除外
- リアルタイム追加・更新・削除による再取得
- 再取得失敗時に直前の完全な結果を維持すること

## 初期版の対象外

- 「前震」「余震」の自動分類
- 無感地震・微小地震カタログの取り込み
- 活動増加の自動判定、危険度予測、将来予測
- プッシュ通知
- 専用バックエンド API
- b 値、ETAS などの統計解析
