# 電文一覧のリアルタイム更新・表示改善 設計

## 目的

地震履歴詳細画面から開く電文一覧で、同一地震のWebSocket更新を受けた際に一覧と詳細を更新する。あわせて、震度表示を共通コンポーネントへ統一し、市区町村を都道府県単位で改行し、旧値が不明な擬似的な震源差分を表示しない。

## 現状と原因

- ページは一覧と詳細のProviderを `ref.watch` しているため、`ref.read` が更新を止めているわけではない。
- 一覧・詳細NotifierはREST取得のみで、`realtimeEventsProvider` を購読していない。
- 震度表示は共通の `JmaIntensityIcon` ではなく独自の `Container` と `Text` で描画している。
- VXSE53の都道府県名と市区町村は1つの `Wrap` に並べられ、県が変わっても同じ行に続く。
- 震源差分計算が旧値のない状態も変更と判定するため、`M不明→M3.8` のような擬似差分が表示される。

## 設計

### リアルタイム更新

`TelegramListByEventId` と `TelegramDetails` がそれぞれ `realtimeEventsProvider` を購読する。同一 `eventId` の `RealtimeEarthquakeUpsertEvent` を受けた場合だけ自身を無効化し、RESTから再取得する。別地震の更新、Ready、EEWなど他種別のイベントでは再取得しない。

ページ層にはWebSocket購読や再取得の副作用を追加しない。ページは現在どおりProviderを `ref.watch` し、再取得された状態を描画する。

### 震度表示

`IntensityRegionList` の独自震度バッジを `JmaIntensityIcon` の filled 表示へ置き換える。これにより、少なくともVXSE51（震度速報）とVXSE53（震源・震度速報）でアプリ共通の震度色・文字組みを使う。同じリストを使うVXSE62も同じ表示へ統一する。

### 都道府県ごとの改行

VXSE53の市区町村は、震度階級内で都道府県コードごとにグループ化する。各都道府県を独立した行として `Column` に配置し、行内だけを `Wrap` して「茨城県 市A 市B」のように表示する。次の都道府県は表示幅にかかわらず必ず次行から始める。

### 震源差分

旧震源情報がない場合、または比較対象の旧値が不明な場合は、その項目を差分として表示しない。`M3.8→M4.0`、深さや震源名の既知値同士の実際の訂正は従来どおり表示する。

## エラー処理

WebSocketイベント後の再取得に失敗した場合は既存のAsyncValue/CachedNotifierのエラー表示とキャッシュ保持を利用し、例外文字列を新たに画面へ直接展開しない。固定値や推測値へのフォールバックは追加しない。

## テスト

- 同一 `eventId` の地震更新で一覧APIと詳細APIが再取得されること。
- 別 `eventId` と他種別イベントでは再取得されないこと。
- 震度行が `JmaIntensityIcon` を描画すること。
- 十分な横幅でも異なる都道府県が別行になること。
- 旧値不明から既知値への変化は差分に含めず、既知値同士の訂正は残ること。

実装は各テストを先に追加して期待どおり失敗することを確認し、その後に最小の修正を行う。

## 対象外

- WebSocketプロトコルやサーバー側イベント形式の変更
- 電文一覧全体のデザイン刷新
- 震度地域・市区町村の差分注釈仕様の変更
