# 地震履歴デバッグフィルター表示制御 設計

## 目的

地震履歴一覧のステータスフィルターと電文種別フィルターを、デバッグ画面の「デバッグモード」が有効な場合にだけ表示する。

## 表示条件

- デバッグモードの判定には `debugProvider` を使用する。
- `debugProvider` が `true` の場合だけ、ステータスフィルターを表示する。
- `debugProvider` が `true` かつ地域絞り込み中でない場合だけ、電文種別フィルターを表示する。
- `debugProvider` が読み込み中またはエラーの場合は、両フィルターを非表示にする。
- `kDebugMode` を直接の表示条件には使用しない。デバッグビルドでも、デバッグ画面のフラグが無効なら表示しない。

## 実装方針

`EarthquakeHistoryParameterPersistentDelegate` 内の `_FilterChipBar` は既に `ConsumerWidget` であるため、そこで `debugProvider` を監視する。既存のチップ順序、アクティブなチップを先頭に並べる処理、地域絞り込み時の制約は維持する。

APIパラメータとフィルター値は変更しない。既存の画面遷移などからステータスまたは電文種別が指定された場合でも値は保持し、UI上のチップだけを非表示にする。

## テスト

Widgetテストで次を検証する。

- デバッグモードが無効な場合、ステータスと電文種別のフィルターチップが表示されない。
- デバッグモードが有効な場合、ステータスと電文種別のフィルターチップが表示される。

既存の個別フィルターチップの操作テストは変更しない。
