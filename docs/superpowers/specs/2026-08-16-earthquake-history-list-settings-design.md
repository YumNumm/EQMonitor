# 地震履歴一覧の背景色・日付見出し設定 設計

## 背景

地震履歴設定には「最大震度ごとの背景塗りつぶし」が保存されているが、
地震履歴一覧が設定を購読せず、`EarthquakeHistoryListTile` の既定値を
使用しているため、設定をオフにしても背景色が表示される。

また、地震履歴一覧は並び順にかかわらず日付単位のグループリストを使い、
日付見出しを固定表示している。日付以外の並び順では、グループ化によって
取得済み項目が日付単位に再配置され、選択したソート順を維持できない。

## 目的

- 背景塗りつぶし設定を地震履歴一覧へ反映する。
- 日付見出しの表示方法を利用者が選択できるようにする。
- 日付見出しを表示しない場合は、APIから返された並び順を維持する。
- 既存の保存済み設定を安全に読み込めるようにする。

## 設定モデル

`EarthquakeHistoryListConfig` に日付見出しの表示モードを追加する。

- `always`: 常に表示
- `onlyWhenDateSort`: 発生時刻順のときのみ表示
- `never`: 表示しない

既定値は `onlyWhenDateSort` とする。既存JSONに新しいキーがない場合も
Freezed / json_serializable のデフォルト値によって同じ値へ復元する。

発生時刻順は `EarthquakeSortBy.eventId` で表現されるため、昇順・降順の
どちらも日付ソートとして扱う。

## 設定画面

地震履歴一覧セクションに「日付見出し」を追加し、次の3項目を
ラジオ選択として表示する。

- 常に表示
- 発生時刻順のときのみ
- 表示しない

選択時は既存の `EarthquakeHistoryConfigNotifier.save` を通して設定全体を
保存する。背景塗りつぶしのスイッチは既存UIを維持する。

## 一覧表示

地震履歴一覧は `earthquakeHistoryConfigProvider` の一覧設定を購読する。

- `isFillBackground` を各 `EarthquakeHistoryListTile` の
  `showBackgroundColor` に渡す。
- 表示モードと現在の `sortBy` から日付見出しの表示可否を決める。
- 表示する場合は `SliverGroupedPagingList` を使い、現在と同じ固定見出しを
  表示する。
- 表示しない場合は `SliverPagingList` を使い、データソースの項目順を
  変更せずに表示する。

グループ表示と通常表示で、行の内容、ローディング、エラー、空表示、
追加読み込みの表示は共通化し、挙動差を日付見出しの有無だけに限定する。

## テスト

- 既存JSONから新しい既定値を復元できること。
- 3つの表示モードをJSONで往復できること。
- 各表示モードとソート項目の組み合わせから表示可否を正しく判定すること。
- 設定画面で3つの選択肢を表示し、選択内容を保存できること。
- 一覧設定に応じて背景色の有無が切り替わること。
- 日付見出しの表示時はグループ一覧、非表示時は通常一覧になること。

## 対象外

- 日付見出しのデザイン変更。
- 日付の書式やタイムゾーン処理の変更。
- ホーム画面の地震履歴カードの背景表示変更。
