# 距離減衰式・地域到達時刻修正 設計

## 背景

EEWの推定震度表示では、観測点ごとの予想計測震度を距離減衰式で計算し、その結果を気象庁の予報区単位に集約している。

現行実装には次の3つの独立した誤りがある。

- 断層半径を震央距離から控除した後、震源距離からも控除しており、断層半径を実質2回差し引いている
- JMA2001走時表の距離軸は震央距離だが、深さを合成した震源距離を渡している
- 地域の到達予想時刻を、地域内で最も早くS波が到達する地点ではなく、最大震度を予測した地点から求めている

このため、特に大きな地震で予想震度を過大評価し、深い地震では到達を遅く見積もり、地域内の最大震度地点と最短到達地点が異なる場合には地域の到達予想時刻を誤る。

## 方針

距離減衰式では、地点と震央の地表距離から震源距離を一度だけ計算し、そこから断層半径を1回だけ差し引く。

```text
hypocentralDistance = sqrt(depth^2 + epicentralDistance^2)
faultRadius = 10^(0.5 * Mw - 1.85) / 2
x = max(hypocentralDistance - faultRadius, 3)
```

Mw変換、司・翠川式、Vs=600m/sからVs=400m/sへの補正、ARV400による地表増幅、最大速度から計測震度への変換は変更しない。

地域集計は、Riverpod Providerから独立した純粋な `EewEstimatedRegionCalculator` に切り出す。Calculatorは観測点、観測点ごとの推定震度、震源位置・深さ・発震時刻、走時表を受け取り、次の2値を独立に集約する。

- `intensity`: 地域内の観測点で最大の推定計測震度
- `sWaveArrivalTime`: 地域内の全対象観測点で最小のS波走時を発震時刻へ加えた時刻

走時表の検索には地点と震央の地表距離、すなわち震央距離を渡す。最大震度地点を到達時刻の代表点にはしない。

## コンポーネント

### EstimatedIntensityDataSource

観測点ごとの推定計測震度を算出する責務を維持する。震央距離をそのまま震源距離計算へ使い、断層半径の二重控除だけを解消する。

### EewEstimatedRegionCalculator

地域集計専用の純粋クラスとして追加する。観測点と推定震度の件数が一致しない場合は、誤った地域情報を返さず空リストを返す。

発震時刻がない場合も最大震度集計は行い、到達予想時刻だけを `null` にする。走時表の範囲外で一部地点の走時を取得できない場合は取得可能な地点の最小値を採用し、全地点で取得できない場合だけ `null` とする。

到達時刻の対象集合は、現行の推定震度対象と同じARV400を持つ観測点とする。ARV400を持たない地点まで対象に広げる変更は、この不具合修正には含めない。

### EewEstimatedRegionIntensity Provider

入力値の妥当性確認、観測点インデックス・Isolate・走時表の取得、単一震源の推定震度計算を担当する。地域集計処理は `EewEstimatedRegionCalculator` へ委譲する。

## テスト

距離減衰式には、震央距離と深さから求めた震源距離に対して断層半径が1回だけ控除されることを、手計算した期待値で確認する回帰テストを追加する。断層半径を二重控除する旧実装では失敗する入力を使う。

地域集計には次の回帰テストを追加する。

- 同一地域で、近い低震度地点と遠い高震度地点がある場合、震度は高震度地点、到達時刻は近い地点から採用する
- JMA2001走時表へ震源距離ではなく震央距離を渡す
- 複数地域をregionCodeごとに独立して最大震度・最早到達時刻へ集約する
- 発震時刻なし、走時範囲外、観測点と震度の件数不一致を安全に処理する

既存のIsolateテストと関連するEEW表示テストも実行し、計算結果の配列契約と利用側表示に回帰がないことを確認する。
