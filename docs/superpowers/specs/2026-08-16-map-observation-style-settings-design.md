# マップ観測点表示設定の修正設計

## 背景

マップレイヤー設定画面には、強震モニタ観測点のサイズと枠表示を
変更する設定がある。設定値の保存は行われているが、観測点レイヤーの
描画定義へ正しく反映されていない。

## 原因

- サイズ係数はレイヤービルダーへ渡されるが、`circle-radius` へ適用されず、
  `circle-stroke-width` だけが変化する。
- 枠表示モードは設定プロバイダーに保存されるが、観測点レイヤーが購読せず、
  現在は全モードで枠が表示される。
- 既存テストは枠線幅の差だけを検証するため、円半径への適用漏れを検出できない。

## 修正方針

既存の `KyoshinMonitorObservationLayerBuilder` を維持し、次の入力から
MapLibre の円レイヤー定義を構築する。

- `radiusScaleFactor`: 小 `0.65`、中 `1.0`、大 `1.35`
- `markerType`: 保存された枠表示モード
- `hasActiveEew`: 生存中の EEW 電文があるか

円半径と枠線幅の補間式を、それぞれ `radiusScaleFactor` で乗算する。
枠を表示しない場合は `circle-stroke-width` を `0` にする。

枠表示条件は次の通りとする。

- `always`: EEW の有無にかかわらず表示
- `onlyEew`: 生存中の EEW 電文が1件以上ある場合のみ表示
- `never`: EEW の有無にかかわらず非表示

観測点レイヤーは枠表示モードと生存中 EEW の有無を購読する。
表示条件またはサイズが変わった場合は、既存の操作キューを利用して
同じ GeoJSON source を維持したまま circle layer のみ再構築する。

## テスト

レイヤービルダーの単体テストで次を確認する。

- 小・中・大で `circle-radius` の式がそれぞれ異なる。
- 半径と枠線幅の両方へ同じサイズ係数が適用される。
- 枠表示時はズーム連動の枠線幅を持つ。
- 枠非表示時は枠線幅が `0` になる。

枠表示モードから実表示条件への変換はレイヤービルダー内で行い、
`always`、`onlyEew`、`never` と EEW 有無の組み合わせを単体テストで固定する。

## 対象外

- 設定値の保存形式や Preferences キーの変更
- 観測点 GeoJSON の構造変更
- 他のマップレイヤーの描画方式変更
