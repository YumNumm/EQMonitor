## 確認した構造

- Case 2の子`1899:405`は`Live Activity Lock`の「バリアント2」instance。
  元の部品`1628:1745`と同じ1132×406、上下32・左右30、間隔8。
- ロック画面は、種別・見出し・MAXを含むヘッダーと、震源情報・現在地・
  到達予想・地域の震度を並べた本文で構成される。
- 警報ヘッダーの背景`#B31918`、枠`#FF5151`、部品の背景は黒。
  震度3のバッジは`#59FF30`と黒文字。アプリの既存震度トークンと照合する。
- `1628:1744`には予報・PLUM・低精度・地域値欠損のバリアントがある。
- `1962:529`には揺れ検知の部品群があるが、EEW由来の例示値も残っている。
- Dynamic Island `1628:1694`は、左上MAX、右上M・深さ、下部見出し・
  現在地の警報表示・到達予想・地域の震度という構成。
- ファイルの注記は、EEW・地震情報・揺れ検知の統合と、現在地の予想震度・
  到達予想がない場合に空きが生じることを許容している。
  実装例への注記には、情報重複・余白・Dynamic Typeでの潰れへの指摘がある。

## データとの対応

- 見出し・主情報は新wire契約の`primary`と該当ブロックを使用する。
- デザインの例示値を本番の固定値や欠損値の代用品にしない。
- `shakeDetection.level`は揺れ検知レベルであり、震度に変換しない。
- 新schemaに全国の最大長周期地震動階級はない。
  `eew.location.forecastLpgmIntensity`を全国の最大値として表示しない。
- 取消時は古い予想・観測値を有効情報として表示しない。
  終了の制御はbackendに置き、クライアント独自のタイマーを設けない。
- Figmaの寸法は端末のptと同一視せず、既存のiOS実装と端末幅を確認する。
  テキスト領域を固定高にしてDynamic Typeの文字を切らない。
