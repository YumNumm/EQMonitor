# ドキュメントは日本語で記述する

## ルール

このリポジトリに追加・更新するドキュメントは、日本語で記述する。

対象には `docs/` 配下の設計メモ、TODO、知見、監査レポート、運用手順を含める。ファイル名、コード識別子、コマンド、ログ、API パス、英語の固有名詞は必要に応じてそのまま記載してよいが、説明文・見出し・補足は日本語にする。

## 背景

利用者・開発者が日本語で読む前提のプロジェクトであるため、英語だけのドキュメントを追加しない。監査レポートや作業記録も、最初から日本語で残す。

## 例

```md
# アプリ側 TODO / FIXME / 未実装マーカー監査

- 対象範囲: `app/`
- `FIXME` の検出件数: 0 件
```

英語のコマンドや識別子は、意味を変えずにそのまま残す。

```sh
rg -n --hidden -S "TODO|FIXME" app
```
