# EEW の深さ 150km と予想最大震度は独立

- 日付: 2026-08-22
- 対象: `eew_card.dart`、EEW の震度表示全般
- 関連: [#1729](https://github.com/YumNumm/EQMonitor/issues/1729)

## ルール

深さ 150km 以上であることと、予想最大震度の有無は**同値ではない**。

- 150km 以上でも最大震度が発表される報がある
- 150km 未満でも最大震度が未発表の報がある（PLUM 法、仮定震源要素、精度不足など）

表示は発表内容をそのまま使う。

| 最大震度 | 深さ | すること |
|---|---|---|
| 発表あり | 問わない | 震度を表示する。深発注意文は出さない |
| 未発表 | 150km 未満 | 深発注意文は出さない（理由が深発ではない） |
| 未発表 | 150km 以上 | 深発注意文を出すのは、PLUM / レベル法 / 1点検知など別理由を除外できるときだけ |

「震源の深さが150km以上のため、予想震度は発表されていません」は因果の断定なので、深さだけ・未発表だけで出さない。

## 混同しやすい箇所

- `eewEstimatedRegionIntensityProvider` の `depth >= 150` は、アプリ側の距離減衰推定をスキップする条件。JMA 発表震度の有無ではない
- `_EewMaxIntensitySection` に `depth` を渡しても、深さで震度バッジを消さない
