# `dart format` のバージョン差異によるリポジトリ全体の再フォーマットを検討する

## 背景

Task 10/11（freezed モデル分離・StatefulWidget の Hook 化）作業中に判明。
現在のクラウドエージェント環境の Dart SDK（3.14.0）付属の `dart format` を
既存ファイルにかけると、変更していない箇所まで広範囲に差分が出ることを確認した。

再現手順は `docs/knowledge/20260814_dart_format_version_drift.md` を参照。

## 影響

- 既存ファイルの一部編集時、`dart format <変更ディレクトリ>` を
  そのまま実行すると無関係な diff が大量に混入する。
- 本タスクでは該当ファイルを都度 `git checkout` で差し戻し、
  変更行のみ手動整形することで回避した。

## 対応候補（今後検討）

- CI で使っている Dart SDK / `dart format` のバージョンを固定し、
  ローカル/エージェント環境と揃える。
- リポジトリ全体を対象バージョンの `dart format` で一括再フォーマットする
  （大きな diff になるため、専用 PR として分離する）。
- `melos run format` 相当のコマンドがあれば、バージョン差異の影響範囲を
  定期的に監視する仕組みを検討する。
