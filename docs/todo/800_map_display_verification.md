# 地図の描画・操作・実機検証

実機での可視出力と性能は未検証。

## 800: 地震履歴の観測点キャッシュの実機性能確認

- Android の profile/release で、観測点の多い地震詳細を移動・拡大縮小し、通常震度・長周期・震度DBの表示とフレーム時間を確認する。GeoJSON の再生成抑止による実機での改善幅は未計測。
- 観測データ・配色・表示種別の変更と地図の再作成で最新データが表示されることを確認する。

## 780: EEW と強震モニタの描画順の実機確認

- Home / Live Monitor で、P/S 波の線と震源マーク（点滅中を含む）が強震モニタ観測点より上に表示されることを iOS/Android で確認する。EEW 開始・終了、marker サイズ・枠設定変更、強震モニタ再有効化、P/S 波の表示切替、テーマ変更後も同じ順序を保つことを確認する。
- S 波の塗りつぶしの位置・透明度と、警報区域の塗りつぶしが観測点の下に表示されることを確認する。native の可視出力は未検証。

## 780: 市区町村別最大震度の選択枠と詳細シートの表示確認

- 地図タップ後、市区町村の実際の bounds が詳細シートより上に収まり、選択枠と「観測震度」の選択状態を同時に確認できることを iOS/Android の native 地図で確認する。変更後の native 可視確認は未実施。
- 大崎市など東北の市区町村、小さい市区町村、文字拡大、画面回転、シートの拡大・閉じる操作で枠の表示と操作を確認する。最大震度APIの取得前・失敗時も選択枠を確認する。

## 780: 共通地域選択の実機確認

- `app/lib/feature/region_selection` の一覧・地図・単一／複数選択は自動テストで確認する。iOS/Android の native 地図表示と hit test は未検証。
- Asset Pack v0.1 を使い、都道府県・観測用／通知用細分区域・市区町村・震央領域のタップと選択highlightを確認する。通知地域では横浜が神奈川県東部 `360`、小田原が西部 `361` となり、一覧・地図・保存後の地域が一致することを確認する。震央の海域、境界上の複数候補、地図領域のない地名の一覧選択、旧packの案内も確認する。
- 種別・一覧／地図切替、連打、選択解除中のlookup完了、戻る、theme変更、background復帰で選択が復活せず、layer重複・例外がないことを確認する。
- 小画面・文字拡大で選択確認欄と候補ボタンが操作できることを確認し、端末・OS・build modeと結果を記録する。
