# 地図の描画・操作・実機検証

実機での可視出力と性能は未検証。

## 800: 地震履歴の観測点キャッシュの実機性能確認

- Android の profile/release で、観測点の多い地震詳細を移動・拡大縮小し、通常震度・長周期・震度DBの表示とフレーム時間を確認する。GeoJSON の再生成抑止による実機での改善幅は未計測。
- 観測データ・配色・表示種別の変更と地図の再作成で最新データが表示されることを確認する。

## 790: 強震モニタ観測点の震度アイコンの実機確認

- マップレイヤーのデバッグ欄で「強震モニタの震度アイコン」を有効にし（既定は無効）、リアルタイム震度 0.0 以上の観測点が震度アイコンに切り替わり、0.0 未満と震度以外のデータ種別では従来の円のまま表示されることを iOS/Android で確認する。filter と `icon-image` の `step` 式の native 変換は未検証で、例外が出る場合は解析 isolate で画像 ID を property に書き出す方式へ切り替える。
- リプレイで観測点の多い地震を再生し、`kmoni.updateGeoJsonSource` の所要時間とフレーム時間を確認する。シンボルの毎秒再レイアウトの負荷は未計測。
- 文字入りアイコンへ切り替える zoom（`KyoshinMonitorObservationLayerBuilder.iconTextMinZoom`）と `icon-size` は暫定値。円の直径と見比べて調整し、テーマ変更・観測点サイズ変更・観測点フィルター併用後の表示も確認する。

## 780: EEW と強震モニタの描画順の実機確認

- Home で、P/S 波の線と震源マーク（点滅中を含む）が強震モニタ観測点より上に表示されることを iOS/Android で確認する。EEW 開始・終了、marker サイズ・枠設定変更、強震モニタ再有効化、P/S 波の表示切替、テーマ変更後も同じ順序を保つことを確認する。
- S 波の塗りつぶしの位置・透明度と、警報区域の塗りつぶしが観測点の下に表示されることを確認する。native の可視出力は未検証。

## 780: 市区町村別最大震度の選択枠と詳細シートの表示確認

- 詳細シートの一覧が画面下端まで描画され、末尾までスクロールするとホームインジケーター・ナビゲーションバーと最終項目が重ならないことを iOS/Android 実機で確認する。横画面での左右の安全領域とシートの拡大・縮小も未検証。
- 地図タップ後、市区町村の実際の bounds が詳細シートより上に収まり、選択枠と「観測震度」の選択状態を同時に確認できることを iOS/Android の native 地図で確認する。変更後の native 可視確認は未実施。
- 大崎市など東北の市区町村、小さい市区町村、文字拡大、画面回転、シートの拡大・閉じる操作で枠の表示と操作を確認する。最大震度APIの取得前・失敗時も選択枠を確認する。
- 地震詳細の市区町村ポップアップから開いたとき、初期カメラで選択枠が詳細シートの上に収まることを iOS/Android で確認する。Android でタップ直後に枠とシートが出ること、カメラ移動中の再タップで選択が失われないことも確認する。native の可視確認は未実施（同一レイヤー定義の描画は MapLibre GL JS でのみ確認）。

## 780: 共通地域選択の実機確認

- `app/lib/feature/region_selection` の一覧・地図・単一／複数選択は自動テストで確認する。iOS/Android の native 地図表示と hit test は未検証。
- Asset Pack v0.1 を使い、都道府県・観測用／通知用細分区域・市区町村・震央領域のタップと選択highlightを確認する。通知地域では横浜が神奈川県東部 `360`、小田原が西部 `361` となり、一覧・地図・保存後の地域が一致することを確認する。震央の海域、境界上の複数候補、地図領域のない地名の一覧選択、旧packの案内も確認する。
- 種別・一覧／地図切替、連打、選択解除中のlookup完了、戻る、theme変更、background復帰で選択が復活せず、layer重複・例外がないことを確認する。
- 小画面・文字拡大で選択確認欄と候補ボタンが操作できることを確認し、端末・OS・build modeと結果を記録する。
