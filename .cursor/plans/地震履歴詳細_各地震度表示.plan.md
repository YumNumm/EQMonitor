# 地震履歴詳細「各地の震度」表示と単体テスト計画

## 背景（原因の要約）

- UI は `[PrefectureIntensityWidget](app/lib/feature/earthquake_history/ui/components/prefecture_intensity.dart)` が `EarthquakeIntensity.intensityTree` を描画する。
- `[convertToIntensityTree](app/lib/feature/earthquake_history/data/model/intensity_tree_converter.dart)` は引数なし時 `**intensity.regions` のみ**でツリーを組み、`prefectures` は使わない。`cities` / `stations` は `[toEarthquakeIntensity](app/lib/feature/earthquake_history/data/model/earthquake_intensity.dart)` から**渡されていない**。
- `[packages/eqmonitor_api/lib/src/models/intensity.dart](packages/eqmonitor_api/lib/src/models/intensity.dart)` に `**cities` / `stations` が無く**、API が返しても破棄される。

詳細は調査時点の整理どおり。修正時は **テストファーストで欠落パターンを固定**する。

---

## 単体テスト方針（必須）

### 置き場所・既存との関係

- 既存: `[app/test/feature/earthquake_history/data/model/intensity_tree_converter_test.dart](app/test/feature/earthquake_history/data/model/intensity_tree_converter_test.dart)`（`convertToIntensityTree` の振る舞いが厚い）。
- **追加するケース**は同ファイルにグループを足すか、変換の入口を分離した場合は `earthquake_intensity_test.dart` 等に `**toEarthquakeIntensity` 経由の結合に近いテスト**を置く（重複は避け、**境界は converter に集約**するのがよい）。

### 追加すべきテストケース（名前は例）

| ケース                                            | 入力のイメージ                                                   | 期待                                                             |
| ---------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------------- |
| `regions` に細分区域がありパラメータと一致                     | 既存テストと同型                                                  | 従来どおり非空ツリー（回帰）                                                 |
| `**regions` が空で `cities` のみ**（API が市区町村だけ返す想定） | `api.Intensity` をモック／ビルダで `regions: []`、`cities` に震度付きコード | **修正後**は `_intensityTreeFromCities` 相当で非空（**修正前は失敗＝赤でよい TDD**） |
| `**prefectures` のみ**（細分区域なし）                   | `regions` / `cities` 空、`prefectures` のみ                   | 仕様決め後: 都道府県単位の表示 or 空のどちらかを **期待値として固定**                       |
| `maxIntensity` はあるが `regions` も `cities` も空    | エッジ                                                       | 空 Map または定義したフォールバック                                           |

### 実装メモ

- `api.Intensity` に `cities` が載るよう codegen 後、テストヘルパー `_buildIntensity` を拡張して `**cities` / `stations` を渡せる**ようにする。
- `**dynamic` 禁止ルール**に従い、テストデータは `api` 型で組み立てる。
- 実行: プロジェクトルールに従い `mise exec -- dart test`（対象パスを指定）で CI と同様に確認。

### 完了条件

- 上記ケースが **意図した期待**で緑。
- 既存の `convertToIntensityTree` 関連テストが **すべて**緑（リグレッションなし）。

## 実装順序（推奨）

1. **単体テスト追加**（`cities` のみ等で現状が赤 or 意図した失敗になる状態を明確化）。

3. テスト緑・必要なら期待値の微調整。

## 修正の方向性（参照）

- `eqmonitor_api` の `Intensity` に OpenAPI どおり `cities` / `stations` を取り込む（依存ファイルは手編集せずコマンドで再生成）。
- `toEarthquakeIntensity` で `convertToIntensityTree(..., cities: ..., stations: ...)` を渡す。`prefectures` のみのときのフォールバックは仕様確定後にテストで固定化。
