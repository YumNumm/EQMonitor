# 地震履歴詳細「各地の震度」・マップ連動・現在地（改訂）

## 参照UI（別アプリのイメージ）

- **KyoshinEewViewer 系**の画面を参考にする（ユーザー提供スクショ）。左パネルに **震度階級 → 都道府県 → 市区町村／観測点** の階層ツリー、中央に塗り分け地図と震源、といった情報密度を目安にする。
- EQMonitor では既に `[PrefectureIntensityWidget](app/lib/feature/earthquake_history/ui/components/prefecture_intensity.dart)` が震度グループ化と都道府県配下のリストを担う。**データ欠落修正後**、観測点階層やタップ領域の拡張はこの系統で足す（別画面を増やしすぎない）。

---

## 背景（データ不整合の要約）

- UI は `EarthquakeIntensity.intensityTree` に依存。
- `[convertToIntensityTree](app/lib/feature/earthquake_history/data/model/intensity_tree_converter.dart)` は `**intensity.regions` のみ**でツリーを組み、`prefectures` は未使用。`cities` / `stations` は `[toEarthquakeIntensity](app/lib/feature/earthquake_history/data/model/earthquake_intensity.dart)` から**渡されていない**。
- `[packages/eqmonitor_api/lib/src/models/intensity.dart](packages/eqmonitor_api/lib/src/models/intensity.dart)` に `**cities` / `stations` が無く**、API が返しても破棄される。

修正は **テストファースト**で欠落パターンを固定してから codegen／変換を直す（既存「単体テスト方針」節どおり）。

---

## 新要件 A: ツリー選択 → マップ遷移

### 挙動

- 「各地の震度」ツリーで **細分区域（region／アプリ上の `CityIntensityNode` に相当する粒度）・市区町村・観測点** のいずれかを選択したとき、**詳細マップのカメラ**がその対象の位置へ移動する（パン／必要ならズーム）。
- 実装時点では `[EarthquakeHistoryDetailsMapView](app/lib/feature/earthquake_history/ui/components/earthquake_history_details_map_view.dart)` が **Placeholder** のため、**MapLibre 等の実マップ**が載ったタイミングで `**MapController` に `moveCamera` / `flyTo`** 相当を呼ぶ設計にする。

### 技術メモ

- **選択状態**: `eventId` スコープの `StateProvider` や `@riverpod` で「選択ノード（種別＋コード）」を保持し、マップ側が `ref.listen` でカメラ更新。
- **座標の出し方**:
  - **観測点**: JMA 地震パラメータの観測点緯度経度（既存 `[EarthquakeParameterStationItem](app/lib/core/provider/jma_parameter/jma_earthquake_nearest_observation_point.dart)` と同系のデータ）。
  - **市区町村／細分区域ポリゴン**: `[jma_map](app/lib/core/provider/map/jma_map_provider.dart)`・`[JmaMapUtility](app/lib/core/provider/map/jma_map_utility.dart)` でジオメトリ取得し、**重心または代表点**にフォーカス（詳細マップ計画の「塗りつぶし／ラベル」と整合）。
- ホーム地図の `[MapCameraState](app/lib/feature/home/data/model/map_camera_state.dart)` パターンを流用できるか検討し、履歴詳細専用の小さな `Notifier` に切り出してもよい。

## 新要件 B: 現在地の震度（市区町村 → 細分区域フォールバック＋速報値）

### 挙動

1. **現在地**は `[locationStreamProvider](app/lib/feature/location/data/location.dart)`（Geolocator）から取得。権限エラー時はカードを非表示 or エラー表示（既存アプリの扱いに合わせる）。
2. 緯度経度から **市区町村コード**を解決（例: `[jmaMapAreaInformationCityInside](app/lib/feature/location/data/nearest_jma_feature.dart)` のような **ポリゴン内判定**／nearest。実装時は地震履歴のコード体系と一致する `JmaMapType` を選定）。
3. **震度の決定（優先順）**:

- その地震のデータに **当該市区町村レベルの震度**があればそれを表示。
- **なければ**、同じ位置から解決した **細分区域（region）レベル**の震度にフォールバック。

1. **ラベル**: いずれの場合も、この値が **観測ベースの速報的な性質**であることを UI 上で明示する（文言案: **「速報値」**／補助説明で「参照：震度速報等に基づく」など。文言は string リソース化を検討）。

### 技術メモ

- ロジックは **Widget 直書きを避け**、`EarthquakePartial` + `EarthquakeIntensity` + 現在地 `LatLng` → `AsyncValue<現在地震度表示モデル>` の **Notifier／純粋関数**に寄せ、**単体テスト**で「市あり／市なしで region」「データ欠落」などを表形式で固定する。
- 「市区町村の震度データがない」は **ツリーにノードが無い**・**API の cities に無い**など複数パターンあり得るため、テストケース名で意図を明確にする。

## 単体テスト方針（必須）

### 置き場所・既存との関係

- 既存: `[app/test/feature/earthquake_history/data/model/intensity_tree_converter_test.dart](app/test/feature/earthquake_history/data/model/intensity_tree_converter_test.dart)`。
- **変換**の追加ケースは同ファイルにグループ追加。
- **現在地フォールバック・選択ノード→座標解決**は `test/.../earthquake_history_detail/` 等に **純粋関数テスト**を追加（`geolocator` を直接モックしないよう、入力は `LatLng` と固定したパラメータ／ツリー）。

### 変換まわりの追加ケース（表）

| ケース                        | 入力のイメージ           | 期待                       |
| -------------------------- | ----------------- | ------------------------ |
| `regions` に細分区域がありパラメータと一致 | 既存テストと同型          | 非空ツリー（回帰）                |
| `regions` が空で `cities` のみ  | `cities` に震度付きコード | 修正後は非空（TDD 可）            |
| `prefectures` のみ           | 細分区域・市なし          | 仕様どおり都道府県表示 or 空を **固定** |
| `maxIntensity` はあるが子が全空    | エッジ               | 空 Map 等を固定               |

### ナビゲーション／現在地まわりの追加ケース（例）

- 同じ `LatLng` で「市レベル震度あり」→ 市の震度が選ばれる。
- 市レベルなし・region のみ → region の震度・**速報値フラグ true**（または専用文言用 enum）。
- 選択コードがパラメータに存在しない → エラー／無表示の仕様をテストで固定。

### 完了条件

- 上記が緑、既存 `convertToIntensityTree` 関連がすべて緑。

## 実装順序（推奨）

1. **データ修正**: 単体テスト追加（赤）→ codegen と `toEarthquakeIntensity`／`convertToIntensityTree` 修正 → 緑。
2. **UX**: ツリー階層の整理（参照UIに近づける）。
3. **マップ**: マップ実装（または既存ブランチ）と合流後、**選択 → カメラ**を接続。
4. **現在地カード**: Notifier + UI + テスト。

マップ本体は [地震履歴詳細マップ計画](地震履歴詳細マップ_f46f62c4.plan.md) と重複するため、**カメラ API の契約**（選択モデル → `Geographic` + zoom）だけ先に共通化すると実装が並行しやすい。

## 修正の方向性（データ層・参照）

- `eqmonitor_api` の `Intensity` に OpenAPI どおり `cities` / `stations` を取り込む（依存はコマンドで再生成）。
- `toEarthquakeIntensity` で `convertToIntensityTree(..., cities: ..., stations: ...)` を渡す。`prefectures` のみ時のフォールバックは仕様＋テストで固定。
