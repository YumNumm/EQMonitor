# shake_eew_correlator

揺れ検知イベントが発表中の緊急地震速報（EEW）と同じ地震によるものかを判定する純 Dart パッケージ。

eqmonitor-backend の `packages/event-correlator` の判定を移植し、端末内検知に合わせて条件を変えたもの。

1. 観測点ごとに、その観測点の検知時刻が P 波到達の 5 秒前から S 波到達 + 30 秒の範囲にあるか
2. 範囲内の観測点について、観測震度が予測震度（司・翠川式 + 地盤増幅率）を 1.5 を超えて上回らないか
3. 震度を観測できた観測点のうち、1 と 2 を満たす観測点の割合が 0.3 以上か

複数の EEW が成立した場合は、スコア、一致数、平均時間差の小ささ、発表時刻の新しさ、イベント ID の順で 1 件を選ぶ。

## backend との差分

- 時間条件は、イベントの発生時刻ではなく観測点ごとの検知時刻で判定する。端末内検知は観測点をイベントの終了まで外さず、揺れの広がりに合わせて観測点が増え続ける。発生時刻で判定すると、後から加わった観測点が P 波到達前として対象から外れる。
- 割合の分母は、時間条件を満たす観測点ではなく、震度を観測できた観測点の全体とする。時間条件を満たす観測点だけを分母にすると、波面がイベントの一部に重なっただけの別の EEW も成立する。
- P 波到達より 5 秒早い検知まで認める。早い報の震源・発生時刻の誤差を見込むためである。
- 震度条件は予測震度を上回る側だけを制限する。検知するのは初期微動であることが多く、主要動の予測震度を 2〜3 下回る。小さい震度では予測式が大きめに出ることもあり、主要動の到達後も下回ったままになる。backend は差の絶対値で判定する。
- `ShakeObservation.isBootstrap` が `true` のイベントは、検知時刻が揺れ始めより後になるため、時間条件の上限（S 波到達 + 30 秒）を適用しない。
- backend は最終報・取消・発表から 300 秒以上の EEW を対象外にする。本パッケージは取消だけを除外し、どの EEW を対象にするかは呼び出し側が選別する。アプリは表示中の EEW を対象にするため、最終報の後も表示が続く間は結合を維持する。
